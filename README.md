## Descrição

**Yu-Gi-Oh! Card Explorer** é uma aplicação em PHP que permite buscar e explorar informações detalhadas sobre cartas do jogo Yu-Gi-Oh!, incluindo nome, tipo, atributo, descrição, preços e conjuntos. O projeto usa a API pública da YGOPRODeck para entregar uma experiência simples, visual e pronta para portfólio.

> Nota para o dono do repositório: o nome `Yu-Gi-Oh-` é ambíguo. O ideal é renomear o repositório para `yugioh-card-explorer`.

## Funcionalidades

- Busca de cartas por nome com paginação funcional.
- Exibição de imagem, tipo, raça, atributo, nível, descrição, arquétipo e preços.
- Estados de interface para busca vazia e nenhuma carta encontrada.
- Visual responsivo com Bootstrap 5 e CSS personalizado.
- Proteções básicas contra entrada inválida e falhas na API.

## Instalação

1. Clone este repositório para o seu ambiente local:
    ```bash
    git clone https://github.com/AndersonCav/Yu-Gi-Oh-.git
    ```
2. Navegue até o diretório do projeto:
    ```bash
    cd Yu-Gi-Oh-
    ```
3. Configure o servidor PHP para servir os arquivos do projeto.

4. Abra o projeto em seu navegador:
    ```arduino
    http://localhost/Yu-Gi-Oh-
    ```

5. Configure a API do Yu-Gi-Oh! se quiser adaptar o projeto para fontes adicionais no futuro.

## Uso

1. Navegue até a interface principal da aplicação.
2. Utilize a barra de pesquisa para buscar cartas por nome ou tipo.
3. Clique em uma carta nos resultados da pesquisa para ver os detalhes completos.
